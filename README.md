# GitHub Star Notes 🌟

为 GitHub Star 仓库添加标签和备注，数据完全本地存储，无需登录，保护隐私。

## 功能

- **详情页**：在仓库页面 Star 按钮旁显示编辑按钮，点击弹出面板记录标签和备注
- **列表页**：在 Stars 列表页每个仓库旁显示角标，hover 预览备注内容
- **Popup**：点击插件图标，查看所有备注、搜索过滤、导出 JSON
- **完全本地**：数据存储在 chrome.storage.local，不联网，不上传

## 安装方法

1. 下载并解压这个文件夹
2. 打开 Chrome，地址栏输入 `chrome://extensions/`
3. 右上角开启「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择本文件夹

## 使用方法

**记录备注（仓库详情页）**
- 打开任意 GitHub 仓库页面
- 找到 Star 按钮旁边的 ✏️ 按钮，点击
- 输入标签（回车添加）和备注，点击保存

**查看备注（Stars 列表页）**
- 打开 github.com/stars
- 有备注的仓库旁会有金色角标
- 鼠标悬停角标可预览标签和备注

**管理和导出**
- 点击 Chrome 工具栏的插件图标
- 可搜索所有备注
- 点击「导出 JSON」备份数据

## 数据格式

```json
{
  "facebook/react": {
    "tags": ["前端", "框架"],
    "note": "React 核心库，用于构建 UI",
    "updatedAt": "2026-05-01"
  }
}
```
